# FisioSist
Simuladores interactivos para la enseñanza de la Fisiología de Sistemas, con énfasis en los mecanismos de la fisiología celular y su integración progresiva en tejidos, órganos y sistemas. Permiten explorar cómo la actividad celular sustenta las funciones del organismo mediante experimentos virtuales, de forma dinámica y sin instalar software
